# Single-stamp design exploration

Replacement ideation set, 26 September 2026. Awaiting selection; no application changes have been made for these designs.

## Brief

The user clarified that 80–90% of sites have one stamp. The remaining 10–20% commonly have about six. These ten full-page renders make one stamp the default and include a separately labeled six-stamp component study below each footer. The gray alternative-state strip is not part of the proposed webpage.

- One compact stamp integrated into the page, without empty gallery slots or a dedicated stamp sidebar.
- Around six stamps expand into a horizontal grid when needed.
- Stamping locations stay in one minimal, collapsed row. Practical details appear only when expanded.
- Traditional maximum page width, readable article, restrained typography, little repeated information.
- Two fictional June 2019 visits; one stamp collected on the first visit and no additional stamp on the second.
- Original fictional diary and the existing NPS Lower Falls photo reference.
- Places browsing stays available through a collapsible browser or menu; it is separate from stamping locations.

## Review and implementation caveats

All ten images were visually checked for exactly one main-page stamp, six stamps in the separate alternative, a closed locations row, visible footer, and complete content. These are generated design references, not an implementation or pixel-perfect specifications. Minor generated copy errors, footer years, invented slogans, and incidental labels must not become product requirements. The fixed fictional visit dates and actual content model remain authoritative. No generated artwork or fictional visits belong in the real collection.

This set supersedes [the prior ten-option set](../exploration-2026-09-26/README.md). Select a direction before implementation. Preserve the user's earlier requirements for a park locator map and mobile reading order when refining the selected direction; this exploration concentrates on stamp count and page hierarchy and does not resolve every secondary detail.
